# آکادمی پایتون النا (Elena Python Academy)

پلتفرم آموزش تعاملی Python با روایت داستانی، اجرای واقعی کد در مرورگر (Pyodide)، چرخه شارژ ۶۰ ثانیه‌ای، اسلایدر مقایسه قبل و بعد، و انطباق کامل با سرفصل‌های بین‌المللی **PCEP™** و **PCAP™**.

## ساختار پوشه‌ها (آماده دیپلوی مستقیم روی GitHub Pages)
- `index.html`: صفحه اصلی وب‌اپلیکیشن
- `css/style.css`: استایل‌های کامل راست‌به‌چپ با فونت وزیرمتن و طراحی تاریک لوکس
- `js/app.js`: موتور گیم‌پلی، تایمر ۶۰ ثانیه‌ای، اسلایدر مقایسه قبل و بعد، سیستم راهنمای ریاضی ۲ تلاشه و ذخیره پیشرفت
- `js/assets-fallback.js`: نمایشگر جایگزین هوشمند تا زمان قرارگیری تصاویر نهایی
- `courses/python/lessons.js`: بانک کامل ۸۰ درس در ۴ فصل (مدیترانه، پاریس، میلان، توکیو و کیوتو)
- `assets/characters/elena-python/`: محل قرارگیری ۱۶۰ تصویر نهایی (`lesson_01_before.png` تا `lesson_80_after.png`)
- `.nojekyll`: جلوگیری از تداخل Jekyll در GitHub Pages
