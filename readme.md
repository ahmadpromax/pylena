# 🐍 آکادمی پایتون النا (Elena Python Academy)

> **تبدیل یادگیری برنامه‌نویسی Python از یک تجربه خشک و تئوریک به یک سفر داستانی، احساسی، بصری و پاداش‌محور با انطباق ۱۰۰٪ با آزمون‌های بین‌المللی PCEP™ و PCAP™**

## 📖 درباره پروژه و چشم‌انداز محصول

**آکادمی پایتون النا** یک پلتفرم آموزش تعاملی زبان برنامه‌نویسی Python است که یادگیری کدنویسی را با **روایت داستانی (Narrative Micro-Lessons)**، **تحول بصری کاراکتر** و **اجرای واقعی کد در مرورگر** ترکیب می‌کند.

### 🎭 شخصیت‌ها و داستان

* **النا (Elena):** بانویی ۳۸ ساله، بالغ، جذاب و باوقار که برای درخشش در ضیافت‌های اشرافی، جذب سرمایه‌گذاران بین‌المللی و سفر به پایتخت‌های مد جهان، به مهارت‌های برنامه‌نویسی Python شما تکیه می‌کند.

* **کمیل (Camille):** مشاور استایل و تشریفات النا که در قالب گفتگوهای زنده و چندپرده‌ای، مفاهیم برنامه‌نویسی را به زبان ساده و بر اساس نیازهای واقعی داستان آموزش می‌دهد.

## ✨ ویژگی‌های کلیدی و حلقه گیم‌پلی (Core Gameplay Loop)

1. **اجرای واقعی Python 3 در مرورگر (بدون نیاز به سرور):**
   مجهز به موتور **Pyodide** (WebAssembly) که کدهای شما را مستقیماً در محیط مرورگر اجرا، اعتبارسنجی و خروجی آن را در کنسول اختصاصی نمایش می‌دهد.

2. **چرخه ۶۰ ثانیه‌ای شارژ و کمد لباس انباشته (60s Charge Cycle):**

   * با حل صحیح چالش هر درس، النا به مدت **۶۰ ثانیه** کاملاً درخشان، آراسته و شارژ می‌شود.

   * پس از اتمام ۶۰ ثانیه، هیچ‌یک از آیتم‌ها و لباس‌های آزادشده حذف نمی‌شوند (**کمد لباس انباشته**)، اما ظاهر النا به حالت عادی/پژمرده برمی‌گردد تا انگیزه ادامه یادگیری و شارژ مجدد حفظ شود.

3. **نمای متمرکز تحول و اسلایدر مقایسه قبل و بعد (Spotlight & Before/After Slider):**
   بلافاصله پس از اجرای موفق کد، پس‌زمینه مات (Backdrop Blur) می‌شود، انتقال نرم (Crossfade) تصویر قبل به بعد نمایش داده می‌شود و یک **اسلایدر تعاملی مقایسه** همراه با نجوای اختصاصی النا فعال می‌گردد.

4. **سیستم چالش ریاضی ۲ تلاشه برای دریافت راهنما:**
   در کنار کنسول خروجی، یک باکس فشرده چالش ریاضی قرار دارد. بازیکن حداکثر **۲ فرصت** دارد تا با حل معادله، راهنمای کدنویسی آن درس را باز کند؛ در غیر این صورت باکس چالش ناپدید می‌شود و مأموریت اصلی همچنان قابل حل باقی می‌ماند.

5. **ذخیره‌سازی خودکار پیشرفت:**
   تمام دروس تکمیل‌شده، آیتم‌های کمد لباس و وضعیت فعلی بازیکن به صورت خودکار در مرورگر ذخیره می‌شود.

## 🗺️ نقشه آموزشی ۸۰ درسی (۴ فصل × ۲۰ درس)

این دوره در ۴ ایستگاه جهانی طراحی شده است و در پایان هر فصل (دروس ۲۰، ۴۰، ۶۰ و ۸۰)، یک **آزمون جامع شبیه‌سازی‌شده** برگزار می‌شود:

| فصل | بازه دروس | لوکیشن و کشور | سرفصل‌های تخصصی Python | دستاورد داستانی و انطباق آزمون | 
| ----- | ----- | ----- | ----- | ----- | 
| **فصل ۱** | دروس ۱ تا ۲۰ | 🌊 **مدیترانه** (پنت‌هاوس و ویلای ساحلی) | متغیرها، انواع داده، عملگرها، رشته‌ها (`f-strings`)، منطق بولین و شرط‌ها (`if/elif/else`) | پوشش بخش اول **PCEP™** • پیراهن شب ابریشمی زرشکی و جواهرات طلایی | 
| **فصل ۲** | دروس ۲۱ تا ۴۰ | 🗼 **پاریس، فرانسه** (مزون‌های اوت کوتور و اپرا) | حلقه‌های `for` و `while`، لیست‌ها، Slicing، تاپل‌ها (`Tuple`)، دیکشنری‌ها و مجموعه‌ها (`Set`) | پوشش کامل **PCEP™** • استایل اشرافی پاریسی و لینک آزمون رسمی | 
| **فصل ۳** | دروس ۴۱ تا ۶۰ | 🇮🇹 **میلان و دریاچه کومو** (کاخ‌های کلاسیک) | توابع (`def`)، حوزه متغیرها (`Scope`)، ماژول‌ها، مدیریت فایل و استثناها (`try/except`) | پوشش بخش اول **PCAP™** • اندام ورزیده، لباس مخمل و الماس ایتالیایی | 
| **فصل ۴** | دروس ۶۱ تا ۸۰ | 🗾 **توکیو و کیوتو، ژاپن** (برج مدرن و باغ سنتی) | برنامه‌نویسی شی‌گرا (**OOP**)، کلاس‌ها، `__init__`، ارث‌بری، چندریختی و Comprehensions | پوشش کامل **PCAP™** • اوج شکوفایی برند شخصی النا و لینک آزمون رسمی | 

## 🏗️ معماری فنی و ساختار پوشه‌ها

معماری پروژه به صورت کاملاً ماژولار و ایزوله طراحی شده تا آماده مقیاس‌پذیری برای زبان‌های برنامه‌نویسی دیگر (مانند JavaScript در آینده) و بارگذاری مستقیم دارایی‌های استاتیک باشد:

```
pylena/
├── index.html                          # ساختار اصلی رابط کاربری و مودال‌های تعاملی
├── README.md                           # مستندات جامع پروژه
├── css/
│   └── style.css                       # استایل‌های راست‌به‌چپ، تم تاریک لوکس و اسلایدر مقایسه
├── js/
│   ├── app.js                          # موتور گیم‌پلی، اجرای Pyodide، تایمر ۶۰ ثانیه‌ای و مدیریت وضعیت
│   └── assets-fallback.js              # سیستم بارگذاری تصاویر با گرافیک جایگزین هوشمند
├── courses/
│   └── python/
│       └── lessons.js                  # پایگاه داده کامل ۸۰ درس، سناریوها، کدهای پایه و اعتبارسنجی
└── assets/
    └── characters/
        └── elena-python/               # محل قرارگیری ۱۶۰ تصویر نهایی (lesson_01_before تا lesson_80_after)

```

## 🚀 نحوه اجرا و دیپلوی روی GitHub Pages

این پروژه بدون نیاز به هیچ وابستگی سمت سرور (Backend) یا مرحله Build اجرا می‌شود:

1. مخزن را روی GitHub کلون یا آپلود کنید.

2. وارد بخش **Settings > Pages** در مخزن خود شوید.

3. در قسمت **Build and deployment**، گزینه **Source** را روی `Deploy from a branch` قرار دهید.

4. شاخه `main` و مسیر `/ (root)` را انتخاب کرده و **Save** را بزنید.

5. پس از چند لحظه وب‌اپلیکیشن روی آدرس `https://<username>.github.io/<repo-name>/` در دسترس خواهد بود.

## 🎨 استاندارد تولید دارایی‌های بصری (Pre-Production Asset Pipeline)

* تمام ۱۶۰ تصویر کاراکتر النا (`lesson_01_before.png` تا `lesson_80_after.png`) به صورت استاتیک و از پیش تولید شده در مسیر `assets/characters/elena-python/` قرار می‌گیرند.

* تا پیش از قرارگیری تصاویر نهایی، ماژول `assets-fallback.js` به طور خودکار کارت‌های وضعیت قبل و بعد را رندر می‌کند تا رابط کاربری بدون هیچ خطا یا تصویر شکسته‌ای عمل کند.
